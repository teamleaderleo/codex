## Batch synthesis

1. **The older slice has a real quality centre.** Median 23/30 is far below the current batch’s 27.5, with six C reports and four reports at D–F.
2. **Doctor dumps are not evidence.** #35391 is almost content-free despite enormous environment output; #35397 and #35393 also pay first-screen costs for oversized diagnostics.
3. **Source inspection can either resolve or destroy a report.** It makes #35387 and #35381 exceptional, but #35382’s own source and test invalidate the claim.
4. **Attribution is a separate burden.** #35383 proves large temp-directory growth but not that Codex’s managed-worktree subsystem created or owns those copies.
5. **Implementation value still diverges from prose quality.** #35393 is only C-grade as a report but contains a credible production-style Windows cleanup mitigation; #35382 contains code-shaped detail with negative implementation value.
6. **Duplicate bots remain weak evidence.** #35380 and #35396 have superficially similar suggested reports, but their triggers and demonstrated boundaries differ materially.
7. **#35613 remains the strongest combined report/contribution comparator.** #35387 and #35381 match its issue-body quality, but neither includes an inspectable tested Codex patch with the same broad validation record.

## New calibration categories

- **Self-refuting report:** later evidence inside the same body disproves the title/opening claim. Do not average the two halves; score the unresolved contradiction as a core clarity/evidence failure.
- **Diagnostic camouflage:** a large doctor report or environment dump surrounds a report that still lacks a trigger, observation, or requested invariant.
- **Ownership leap:** measured damage is real, but the report jumps from correlation to assigning responsibility to a subsystem without proving who created or retained the objects.
